# Getting help

## Documentation

- [README](README.md): features, setup, configuration, and deployment.
- [`frontend/README.md`](frontend/README.md): frontend architecture, roles, and conventions.
- [PROJECT_OVERVIEW.md](PROJECT_OVERVIEW.md): architecture, multi-tenancy, and the full API reference.
- Each backend app (`accounts/`, `curriculum/`, `organizations/`, …) has its own `README.md`.
- With the server running, the interactive API reference is at `/api/docs/` (Swagger UI) and `/api/redoc/`.

## Questions and bug reports

- **Found a bug?** [Open a bug report](../../issues/new/choose).
- **Have an idea?** [Open a feature request](../../issues/new/choose).
- **Have a question?** Search the [existing issues](../../issues?q=is%3Aissue) first. If it isn't answered there, open an issue and describe what you are trying to do.

When asking for help, include your setup (Docker or manual), your OS, and the exact error message or logs.

## Security issues

Do **not** use issues for security problems. See [SECURITY.md](SECURITY.md).

## What's supported

The 🆓 Community edition in this repository is maintained on a best-effort basis by the maintainers and the community. There is no guaranteed response time.

The 💎 Enterprise edition, with commercial support, is offered separately by Pace Wisdom Solutions Pvt. Ltd.
